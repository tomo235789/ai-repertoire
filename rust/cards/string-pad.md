`format!` の幅指定で文字列の左右に文字を詰めて指定の幅にする。固定幅のテキスト表示やログの桁揃えで使う。専用の関数は無く、書式文字列の `{:^8}` / `{:>8}` / `{:*<8}` で寄せ方と埋め文字を指定する。

## Signature

```rust
macro_rules! format { ($($arg:tt)*) => { ... }; }
```

## Usage

```rust
format!("{:^8}", "abc");   // => "  abc   "（中央。余りは右へ）
format!("{:>8}", "abc");   // => "     abc"（右寄せ）
format!("{:*<8}", "abc");  // => "abc*****"（左寄せ、埋め文字 *）
let width = 8;
format!("{:^width$}", "abc"); // => "  abc   "（幅を変数で）
```

## Contract

- `{:<N}` は左寄せ（右に埋める）、`{:>N}` は右寄せ、`{:^N}` は中央寄せ。文字列の既定は左寄せ、数値の既定は右寄せ
- 中央寄せで余りが奇数なら右側が 1 文字多い（`{:^4}` に `"abc"` → `"abc "`、`{:^5}` に `"ab"` → `" ab  "`）
- 埋め文字は寄せ記号の直前に 1 文字書く（`{:*<8}`）。既定は半角スペース。任意の `char` を使えるが（`{:日<8}` も可）1 文字だけ
- 幅は `usize` の変数で `{:>width$}`、位置引数で `{:>1$}`、名前付き引数で `{:>w$}` と書ける
- 幅は **`char`（Unicode スカラー値）の個数** で数える。バイト数でも表示幅でもない。全角文字は 1、結合文字（`e` + U+0301）は 2、ZWJ で結合した家族の絵文字は 5
- 幅が文字数以下なら元の文字列をそのまま返す。切り詰めない
- 新しい `String` を返し、元の値は変更しない。panic しない

## Alternatives

- 数値のゼロ埋めは `{:05}`（符号を先頭に保つ。`-42` → `"-0042"`）。`{:0>5}` は単なる埋め文字で符号を考慮しない
- 標準出力に直接なら `println!("{:>8}", s)`、既存の `String` に追記するなら `std::fmt::Write` の `write!`
- 切り詰めは精度指定 `{:.3}`（`"abcdef"` → `"abc"`）。`{:>8.3}` で切り詰めてから埋められる
- 複数文字のパターンで埋めたい、表示幅（East Asian Width）で揃えたいなら `repeat` で自前で組み立てる（標準には無い）

## Pitfalls

- 自作型の `Display` 実装で `write!(f, "...")` と書くと幅指定が **無視される**。`f.pad("...")` を使うと `{:>8}` が効く
- TypeScript（es-toolkit の `pad`）と Python の f-string `{s:^8}` は余りを右に寄せる点で同じ。Python の `str.center` は幅が奇数だと左に寄せるので違う
- es-toolkit は複数文字の `chars` を繰り返せるが、`format!` は Python の `center` と同じく 1 文字のみ
- `{:.2}` は文字列に対しては **切り詰め** になる（`"abcdef"` → `"ab"`）。数値の小数桁と同じ記法なので取り違えやすい
