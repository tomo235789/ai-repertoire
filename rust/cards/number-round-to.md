`f64::round` は整数にしか丸めないので、10 の n 乗を掛けて丸めて割るイディオムで小数桁を指定する。`.5` は 0 から遠い方へ丸める（Go / C++ と同じ）。表示用の桁揃えや集計値の丸めに使う。

## Signature

```rust
pub fn round(self) -> f64
```

## Usage

```rust
fn round_to(x: f64, digits: i32) -> f64 {
    let p = 10_f64.powi(digits);
    (x * p).round() / p
}

round_to(3.14159, 2);    // => 3.14
round_to(2.5, 0);        // => 3.0（.5 は 0 から遠い方）
round_to(1234.5678, -2); // => 1200.0
```

## Contract

- `f64::round` は最も近い整数（`f64` のまま）を返す。`.5` はゼロから遠い方（`2.5` → `3.0`、`-2.5` → `-3.0`、`0.5` → `1.0`）。偶数丸めではない
- 小数桁の指定は無い。`(x * p).round() / p`（`p = 10_f64.powi(n)`）のイディオムで書く。`n` が負なら `p` が `0.01` などになり 10 の位・100 の位で丸める（`1250.0` → `1300.0`）
- 浮動小数点の補正はしない。`1.005 * 100.0` は `100.49999999999999` なので `round_to(1.005, 2)` は `1.0`。一方 `2.675 * 100.0` は乗算の丸めで `267.5` になり `2.68`。10 進の見た目どおりになるかは値次第
- `NaN` は `NaN`、`inf` は `inf`。`-0.4` は `-0.0`（符号付き零。`== 0.0` は真）
- `x * p` が `f64::MAX` を超えると `inf` になる
- 純粋関数。panic しない

## Alternatives

- 偶数丸め（銀行家の丸め）なら `round_ties_even`（Rust 1.77）。`2.5` → `2.0`、`3.5` → `4.0`、`-2.5` → `-2.0`
- 切り捨て・切り上げ・ゼロ方向は `floor` / `ceil` / `trunc`
- 桁を揃えた文字列（`"1.50"`）が欲しいなら `format!("{:.2}", x)`。書式は 2 進数の正確な値を偶数丸めするので `format!("{:.2}", 2.675)` は `"2.67"`、`format!("{:.0}", 2.5)` は `"2"` と、`round` の結果と食い違う
- 金額など誤差を許容できない値は整数（最小単位）か `rust_decimal` などの 10 進型で扱う

## Pitfalls

- Python の `round()` は偶数丸めで `round(2.5)` が `2`。Rust の `round` は `3.0`。TypeScript（es-toolkit の `round`）は正の無限大方向で `round(-2.5)` が `-2`、Rust は `-3.0`。`.5` ちょうどの値で移植結果が変わる
- `2.675` の 2 桁丸めは Python では `2.67`、Rust のイディオムでは `2.68`。どちらも「正しい四捨五入」ではなく `x * p` の丸め誤差の出方の違い。厳密に丸めたいなら 10 進型を使う
- 整数にするなら `x.round() as i64`。`as` は範囲外で飽和し、`NaN` は `0` になる
- `f32` にも同名の `round` がある。精度が違うので `f64` と混ぜない
